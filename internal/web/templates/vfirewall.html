Firewall

Group your VMs, then write rules between the groups. A VM Group is a set of VMs (drag them in) and/or whole port groups; put each group in the Internal or External zone. Rules are split by where they are enforced: the gateway firewall (North-South) for traffic a gateway routes — between different port groups or to and from External — and the distributed firewall (East-West) for traffic between VMs on the same port group. All membership is drag-and-drop.
Default policies: the gateway firewall is default deny — a gateway no rule applies to forwards everything, but as soon as any rule applies to it, only what a rule allows passes (replies to allowed traffic always do). The distributed firewall is default allow — traffic within a port group passes until a deny rule matches.
