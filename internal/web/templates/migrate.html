Import / Export

Move VMs in and out of VXVisor. Import pulls VMs from vCenter/ESXi read-only (single VM, or a batch with the Plan Migration wizard). Export copies a stopped VXVisor VM out as a disk image, an OVA, or pushes it straight into a vCenter/ESXi.

Plan Migration wizard

Select several VMs, order them, and set each one's name, CPU/RAM, firmware, transfer method, target storage, and network port group — pre-filled from VMware, override any cell. Imports run one at a time in your order; each becomes a ready-to-run instance as it finishes.

{{else}}

{{end}}

Quick Import experimental

Import a single VM's disks directly from vCenter/ESXi, read-only — the source is never powered, snapshotted, or modified. The VM must be powered off. Creates a ready-to-run instance (matching CPU/memory/firmware) plus a reusable base image.

Import a VM disk

Converts a disk from another platform (VMDK, VHD, raw, qcow2) into a reusable base image.

Export a VM

Export a stopped VXVisor VM as a downloadable disk image (qcow2/raw/VMDK) or OVA, or push it into a target vCenter/ESXi. The source VM is only read, never changed.

Note: the exported disk is an exact copy, but whether it boots on another platform depends on the guest's drivers. It may need a driver fix to boot elsewhere.
