Desktop Client

VXVisor Console is a small desktop app for Windows and Linux. It connects to this server, lists your virtual machines, lets you start, stop, restart and open the console of a VM — a quick way to work with a machine without opening the web UI. Download it, run it, and sign in with the same username and password you use here.
