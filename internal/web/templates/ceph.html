Using Ceph for VM disks

When creating an instance, pick the {{if .Pool}}{{.Pool}}{{else}}rbd{{end}} pool and the Ceph RBD disk backend. The VM's disk becomes an RBD image, shared across the cluster — so it can live-migrate between nodes without copying the disk.
