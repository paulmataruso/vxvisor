Import a VM disk

Converts a foreign disk to qcow2 (qemu-img) and registers it as a base image. ESXi: extract the .vmdk from the OVA first. Proxmox: export the volume. Also available as vdxd import <name> <file>.

Import from vCenter / ESXi experimental

{{if .P.IsAdmin}}{{end}}

Imports a VM's disks directly from vCenter/ESXi, read-only — the source VM is never powered, snapshotted, or modified. The VM must be powered off (for a consistent copy). Each disk is streamed in and registered as a base image you can launch. Use a read-only vSphere account.

Join a new worker node (zero-touch)

Give the new host's SSH login and the IPs it should use. VXVisor configures its management + cluster interfaces over SSH and verifies reachability on the new management IP before committing. If it can't reach the node, the node auto-reverts to its original address within 5 minutes (reboot-safe) — it can't be stranded.
