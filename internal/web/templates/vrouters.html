Virtual Routers — route between your networks

{{if .Available}}{{end}}

A vRouter is a software router that connects your internal networks. Give it a transit link on a spare network port, attach the internal port groups your VMs use, and it routes traffic between them — with static routes or dynamic routing. {{if not .Available}} This host can't run a vRouter yet (it needs the container or routing tools installed).{{end}}

{{if .UserMode}}

This host uses simple (user-mode) networking, so VMs on an internal port group can't connect to a vRouter. Switch to bridged networking to route VM traffic (the vRouter still runs).

{{end}}
