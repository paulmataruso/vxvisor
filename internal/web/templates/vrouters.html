Gateways (vRouters) — route between your networks

{{if .Available}}{{end}}

A gateway (vRouter) is a software router that connects your networks. Attach the segments and port groups your VMs use as downlinks and it routes between them — with static routes or dynamic routing. Give it an external interface on a port group your external network carries to reach the outside{{if .InstAdmin}}, or a provider link (Tier-0 uplink) on a spare network port{{end}}. A gateway with a provider link is Tier-0; any other is Tier-1. {{if not .Available}} This host can't run a gateway yet (it needs the container or routing tools installed).{{end}}

{{if .UserMode}}

This host uses simple (user-mode) networking, so VMs on a downlink port group can't connect to a gateway. Switch to bridged networking to route VM traffic (the gateway still runs).

{{end}}

Attach a segment as a downlink — {{.Name}}

{{if $.Segments}}

Only routed (gatewayless) segments appear here. This gateway becomes the segment's gateway, so VMs on any of its downlinks can reach each other at L3. Create a gatewayless segment on the Networks page (leave its gateway blank).

{{else}}

No routed segments are available to attach. On the Networks page, add a segment and leave its gateway blank to make it routable, then attach it here.

{{end}}
{{if eq .Runtime "netns"}}

Attach a port group as a downlink — {{.Name}}

{{if $.PortGroups}}

The gateway joins the port group's VLAN on its vSwitch and becomes its gateway. Only port groups created without a gateway (and not carried out to an external network) appear here.

{{else}}

No routable port groups. On the Networks page, add a port group to a vSwitch and leave its gateway blank, then attach it here.

{{end}}

External interface — {{.Name}}

{{if $.UplinkLegs}}

The gateway joins the port group your external network carries to the physical network and routes your other networks out through it. Its address must be a free host address in that port group's subnet. With NAT on, VMs reach the outside from the gateway's external address; turn it off if the upstream routes your subnets back to this gateway.

{{else}}

None of your vSwitches is connected to an external network. On the Networks page, connect a vSwitch to an external network first (your provider assigns external networks).

{{end}}

Add provider link (Tier-0 uplink) — {{.Name}}

The upstream (provider) router sits on this link; the gateway connects to the rest of your network through it, which makes it Tier-0. The management port and ports already in use are excluded.

New downlink port group — {{.Name}}

Creates an isolated port group (owned by this gateway) that VMs attach to; the gateway IP is their default route. Removing the downlink deletes the port group.
