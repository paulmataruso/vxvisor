Shared storage

Mount NFS, SMB or CephFS shares and attach iSCSI disks. All network storage must use the dedicated storage network, and the server must be on that network — never the management network.

Storage overlay — reach storage across different networks

When the storage server isn't on the same network as your hosts, build a storage overlay so every host can reach it on one shared network. It runs over an existing network port and comes back automatically on reboot. The overlay then becomes the dedicated storage network below.
