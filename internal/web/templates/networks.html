Create VXLAN network

A standalone L2 overlay segment with its own VNI, riding as UDP over any underlay NIC — VMs on it share one broadcast domain across hosts. Give every node the same VNI and list the other nodes' underlay IPs as peers. This is independent of the single cluster overlay.

A per-network bridge (vdxubr<id>) + VXLAN device is created and made reboot-persistent via systemd. VMs attach to it by selecting this network at launch.
