VDI desktops

{{if .PortalURL}}Open VDI Portal ↗{{end}}

A VDI desktop is a VM tagged to a specific user. Create the Windows/Linux VM on the Instances page, then tag it to a user here — they'll see it on the VDI portal and open it in a browser over VNC. Tagged VMs are hidden from the Instances page. A user can hold several and pick which to connect to.
